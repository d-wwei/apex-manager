# Roadmap — 2026-04-16

基于 v0.1.1 bug fix 迭代的 review findings 和开发过程中发现的改进机会。

## High Priority

- [P1] **buildEnvPrefix key validation** — 给 key 加正则校验 `^[A-Z_][A-Z0-9_]*$`，防御性编程。Review finding。
- [P1] **post-create send 轮询替换固定 3s 延迟** — 用 `readScreen` + agent prompt 模式检测替换 `setTimeout(3000)`。当前方案在慢机器上会 race。
- [P1] **buildEnvPrefix 单元测试** — shell 转义、空环境、skip 参数。安全相关函数缺测试覆盖。

## Medium Priority

- [P2] **非 git 模式限制 maxWorkers=1** — 多 Worker 共享项目根目录无隔离，需要限制并发或加文件锁。
- [P2] **API key 不暴露在 tmux scrollback** — 用 `tmux set-environment` 或 env file 替代命令行内联。
- [P2] **exitedWithoutResult 测试覆盖** — monitor.test.ts 缺少 one-shot agent 退出分类的测试。
- [P2] **protocolInjection 语义修正** — codex/gemini/opencode 实际用 post-create send，metadata 标 `stdin` 有歧义。加 `post-create-send` 类型。
- [P2] **非 git 模式通信协议模板** — result.json 模板仍引用 branch/commit 字段，非 git 下无意义。

## Low Priority

- [P3] **isolated: false boundary section 测试** — protocol-builder 新分支无测试。
- [P3] **terminal.ts which() 调用缓存** — detectAdapter 中 `which("cmux")` 被调用两次。
- [P3] **端到端 spawn 测试** — 当前测试只验证 command string，不验证实际 agent 启动。需要 mock terminal adapter。
